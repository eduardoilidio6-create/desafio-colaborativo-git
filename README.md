# Desafio Colaborativo Git

Repositório criado para o desafio em sala, com foco em praticar trabalho colaborativo usando Git e GitHub.

## Sobre o projeto

Este repositório tem como objetivo:

- exercitar o uso de branches;
- simular o fluxo de colaboração entre participantes;
- praticar commits, pull requests e resolução de conflitos;
- organizar um projeto simples de maneira clara e didática.

## Objetivo

O projeto serve como ambiente de aprendizado para desenvolver habilidades de:

- versionamento de código;
- colaboração em equipe;
- revisão de alterações;
- organização de commits e PRs;
- uso do GitHub como ferramenta de trabalho coletivo.
